# Sanitization Report

## Summary

This update keeps existing economy behavior intact while removing publish blockers and making public configuration explicit.

## Code changes made

- Removed the hardcoded Java plugin API key fallback.
- Added a startup warning in the Java plugin when `API_KEY` is missing.
- Changed the FastAPI backend so it refuses to start without `API_KEY`.
- Changed backend API-key middleware to protect every `/api/...` route except `/api/health`.
- Uses constant-time `secrets.compare_digest` for backend API-key comparison.
- Changed the Discord bot so `BACKEND_URL` is configurable from the environment.
- Changed the Discord bot so it refuses to start without `DISCORD_TOKEN` and `API_KEY`.
- Moved Discord role IDs, channel IDs, privileged user IDs, relay bot IDs, DAEMON emoji, and initial DAEMON seed balances to environment variables.
- Added `.env.example`.
- Added `.gitignore`.
- Rewrote `README.md` as a cleaner public/operator guide.
